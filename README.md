# تصميم المعدات — ليلة الامتحان

موقع دراسة تفاعلي لمادة **تصميم المعدات** (د. هيفاء سوادي):
القوانين، والأمثلة المحلولة خطوة بخطوة مع «ليش؟» لكل خطوة، وحاسبات تحط بيها أرقامك.

## تشغيل الموقع على GitHub Pages
1. ادخل على **Settings** بهذا المستودع.
2. من القائمة اختار **Pages**.
3. بخانة **Source** اختار **Deploy from a branch**.
4. اختار الفرع **main** والمجلد **/(root)** واضغط **Save**.
5. بعد دقيقة أو دقيقتين يطلع الرابط: `https://ghoul-04.github.io/equipment-design-exam/`

## تشغيله على Vercel (اختياري)
1. ادخل على vercel.com وسجّل بحساب GitHub.
2. **Add New → Project** واختار `equipment-design-exam`.
3. اضغط **Deploy** بدون أي إعدادات (موقع ثابت، ما يحتاج build).

## الملفات
- `index.html`: كل الصفحات (الرئيسية، الفصل الأول، المثال، ورقة المراجعة…).
- `css/style.css`: التصميم.
- `js/`: الجداول والحاسبات والاختبارات.
- المعادلات تنعرض بمكتبة MathJax من CDN.
